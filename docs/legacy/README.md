# Legacy Docs Index

These files are historical reference material from the retired multi-service topology.

## How To Read Them

- Do not treat old ports like `4002`, `4003`, or `4005` as active runtime defaults.
- Do not use old startup flows that depend on separate Node services unless the document explicitly says it is a migration/archive note.
- Use `start-unified.bat` and `http://127.0.0.1:8080` for current operator workflows.
