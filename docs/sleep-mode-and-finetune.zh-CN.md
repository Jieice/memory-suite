# 开播/下播：自动学习与“睡眠训练”说明

## 目标

- 开播时：稳定秒回，不掉链子。
- 下播后：把弹幕和互动数据用于持续改进（风格/策略），尽量减少手工操作。

## 你现在可直接用的流程

1. 开播前：在 Manager 点 `开播预检`。  
2. 开播中：正常跑，弹幕会进入记忆/样本链路。  
3. 下播后：在 Manager 点 `Sleep Mode`。  
   - 会触发 `Memory Dreaming`（记忆整理）
   - 会触发 `npm run train`（若当前没在训练）

## 需要你手动做什么？

- 日常只需要两步：
  - 开播前点一次 `开播预检`
  - 下播后点一次 `Sleep Mode`
- 不需要每条弹幕手动标注。

## 弹幕能不能用于“微调”？

可以，但建议分层：

- 第一层（当前已具备）：在线记忆 + 策略训练（低风险、可持续）。
- 第二层（后续建议）：把高质量弹幕/回复对做成监督数据集，再周期性 LoRA 微调。

## 建议的安全阈值

- 只采样高质量互动（过滤辱骂/刷屏/重复文案）。
- 每次训练前后跑 `eval:intelligence:stress`，不达标不发布。
- 保留回滚点（模型路径和配置版本化）。
