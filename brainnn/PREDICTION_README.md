# Prediction Engine

Prediction Engine is now an optional Python-side service in the unified Memory Suite runtime.

## Startup

```bash
cd D:\AI\memory-suite\brainnn
python prediction_engine.py
```

## Notes

- The old multi-process launcher is no longer part of the supported startup path.
- Start the main system with `start-unified.bat`.
- If you use prediction features, run this Python service separately.
